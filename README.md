# Web-Scraping-Quotes---Python
A simple and efficient web scraping project built in Python. This script automatically collects quotes and authors from the website [Quotes to Scrape](https://quotes.toscrape.com/) and structures them into a clean Python list of dictionaries.

## Technologies Used
* **Python**
* **Requests** (for fetching web page content)
* **BeautifulSoup4** (for parsing HTML and extracting data)
